# AK09973D 阵列相对一致性校正：基线实验与实现规格

版本：v1.0；日期：2026-10-15。用途：作为后续 AI 辅助编程的需求与算法依据。本文给出实验和软件规格，尚未执行硬件实验；示例阈值属于可配置起点，不是器件保证值。

## 1. 目标与边界

对象为 12 颗 AK09973D 三轴磁传感器，采用正交安装构型，器件间距约 1 mm。使用 PS-3HM355 三维亥姆霍兹线圈、功放、可通过 ROS 控制的信号源。机械臂仅用于放置阵列；基线采集期间保持固定。

目标：在缺少精确电流—磁场模型、背景场复杂的条件下，利用近似均匀的励磁增量场，将各传感器的三轴响应映射到同一参考传感器尺度，减少相对增益、安装角误差及线性轴间耦合导致的不一致，降低均匀场中的伪梯度。

本轮输出每颗传感器的 3×3 相对校正矩阵，不辨识真实零偏，不建立绝对磁场真值，不估计传感器几何位置，不校正交流相位。背景基线是每次实验的现场测量值，不应写成永久器件零偏。

### 1.1 必须成立的条件

- 阵列范围内的线圈增量场近似均匀；静态背景可以空间不均匀。
- 单次“前背景—励磁—后背景”期间阵列与周围物体不动，背景变化近似缓慢。
- 仅使用稳定平台数据，避开建立和衰减过程。
- 三个励磁方向线性独立；不要求准确正交或幅值相同。
- 传感器在线性、未饱和工作区内，配置在采集及运行期间一致。

附近铁磁材料受励磁产生的附加场、环境突发磁扰动和实际空间梯度均不能靠背景插值完全消除。线圈资料标称中心 28×28×28 mm 为 0.1% 均匀区，但这不是阵列现场均匀性的实测证明。

## 2. 数学约定与数据流

全部三维向量使用列向量；离线训练矩阵为 `(3, K)`；实际样本批数据可存为 `(n, 3)`。时间使用同一单调时钟，单位 s；磁场使用名义 μT；几何位置使用 m；梯度使用 μT/m，并可转换为 mT/m。

原始输出先转换为名义阵列坐标：

$$
\mathbf x_i(t)=\mathbf Q_i\,[s\mathbf r_i(t)]
$$

- $\mathbf r_i$：按 HX、HY、HZ 顺序组成的有符号原始计数。
- $s=1.1\ \mu\mathrm T/\mathrm{LSB}$：高灵敏度模式名义系数。
- $\mathbf Q_i$：由安装关系确定的轴交换、符号或名义旋转矩阵；不得默认所有器件均为单位阵。必须核对器件磁轴定义与实际安装。
- $\mathbf T_i$：本次拟合的相对校正矩阵，作用于已经经过 $\mathbf Q_i$ 处理的读数。

物理模型：

$$
\mathbf x_i(t)=\mathbf A_i[\mathbf B_c(t)+\mathbf B_{bg,i}(t)]+\mathbf b_i+\boldsymbol\epsilon_i(t)
$$

短时背景扣除后：

$$
\Delta\mathbf x_{i,k}\approx\mathbf A_i\Delta\mathbf B_{c,k}
$$

选择参考传感器 $r$，理论相对映射为 $\mathbf T_i=\mathbf A_r\mathbf A_i^{-1}$，从而 $\mathbf T_i\Delta\mathbf x_i\approx\Delta\mathbf x_r$。真实 $\Delta\mathbf B_c$ 无需已知。

参考传感器的公共三轴畸变仍然保留。所有传感器一致不等于绝对准确；共同标量增益可消除的定位性质，不可推广为任意共同 3×3 畸变均可消除。

## 3. 设备准备与预采集

1. 使用非磁性夹具，将阵列整体放在线圈中心。机械臂、电机和钢制零件尽量远离中心区域，固定电缆。
2. 确认功放支持所需直流输出及极性。软件输入 0 不自动等于电流为 0；优先监测实际电流。关闭阶段应有可重复的低残余电流状态。
3. 保存 12 个传感器的唯一 ID、总线、TCA 通道、名义轴矩阵与几何位置来源。
4. 当前配置使用高灵敏度、低噪声、连续 500 Hz（使用手册中的 CNTL2=0x0C）。实际轮询速率可能低于芯片内部速率。
5. 全部线圈关闭，采集 30～60 s。按 1 s 小窗口统计均值、波动、有效样本数、DOR 比例和漂移，确定预热是否完成。
6. 挑选重复性好、异常少的参考传感器，不根据最小磁场模长选参考。拟合前冻结参考 ID。
7. 试运行三个方向和三个幅值，确保无饱和且响应充分。输入量和硬件限流由现场确认，不能根据本文自动推断安全上限。

高灵敏度低噪声模式的典型单次噪声为 5.5 μT RMS。稳态平均有助于降低随机噪声，但重复读取旧样本不会增加有效样本数，相关噪声也不保证按 $1/\sqrt N$ 下降。

## 4. 励磁计划

训练计划：X/Y/Z 三轴 × L/M/H 三档幅值 × 正负极性 × 3 次重复，共 54 个 trial。每个 trial 包含独立的前背景、励磁和后背景。

L/M/H 根据实际定位范围设定。可先使名义响应量级约为 0.5/1/2 mT，但这些数值仅用于选择采集范围，不进入回归目标。三轴使用各自的输入档位，不要求电流或场幅值相等。

三轮改变状态顺序并保存随机种子，正负状态可成对安排。初次训练应覆盖三个独立方向。独立验证另采三轴中间幅值及 XY/XZ/YZ 组合场；验证 trial 不参与拟合和参考选择。不能把同一平台的相邻样本随机拆成训练/验证集。

## 5. 单个 trial 的状态机

| 状态 | 硬件操作 | 初始时长 | 处理 |
|---|---|---:|---|
| OFF_PRE_SETTLE | 三轴关闭 | 1 s | 丢弃过渡段 |
| OFF_PRE_CAPTURE | 保持关闭 | 3 s | 记录前背景原始数据 |
| ON_SETTLE | 仅启用指定轴及输入 | 1 s | 丢弃建立过程 |
| ON_CAPTURE | 保持励磁 | 3 s | 记录励磁原始数据 |
| OFF_POST_SETTLE | 三轴关闭 | 1 s | 丢弃衰减过程 |
| OFF_POST_CAPTURE | 保持关闭 | 3 s | 记录后背景原始数据 |
| PROCESS_TRIAL | 保持关闭 | — | 统计、背景插值、质量检查 |
| ACCEPT / RETRY | 保持关闭 | — | 接受记录或有限次重采 |

初始每组约 12 s，54 组约 11 min，不含预热、重采与验证。所有时长可配置。平台不稳定时延长等待并重采，不可只因计时到期就认定稳定。

记录命令发送、应答和状态切换的时间戳。开始采样前必须完成设置；迟到数据按样本时间归属，不按到达主机时的当前状态归属。设备时钟与主机时钟需显式映射；未映射时不能混用。

异常、人工终止或超时均调用 `all_off()`；保留已经采集的数据与失败原因，不得默默跳过。自动重采设置次数上限，达到上限后结束本轮并输出诊断。

## 6. 每个采集窗口的算法

### 6.1 样本筛选

- 排除通信失败、DRDY=0、ERR=1、时间戳非法和不属于平台窗口的样本。
- DOR=1 表示曾有更新被覆盖，不必直接丢弃当前有效新样本；必须记录，并报告有效采样率及覆盖情况。
- 不根据数值相同判断重复样本，因为合法相邻量化读数也可能相同。通过数据就绪标志、固件序号和采集逻辑判断。
- 默认保留原始数值，不进行可能改变增益的自适应滤波。可标记尖峰，但删除策略必须可配置并保存日志。
- 多颗传感器同步跳变时，优先标记整段受扰并重采，不做逐通道强行平滑。

### 6.2 均值、时间及稳定性

对每个传感器、每个窗口分别计算有效计数 $n$、均值 $\boldsymbol\mu$、样本协方差、标准差及平均样本时刻 $\bar t$：

$$
\boldsymbol\mu=\frac1n\sum_j\mathbf x(t_j),\qquad \bar t=\frac1n\sum_j t_j
$$

将窗口分为例如 0.5 s 的子窗口，计算各子窗口均值。可用各轴线性回归斜率、首末子窗口均值差、子窗口均值离散程度检测平台漂移。检测阈值由预采集与任务精度设定，不硬编码为厂家指标。

第一版目标每颗每窗口至少 500 个有效新样本；在实际速率不足时延长窗口。各传感器需覆盖同一时间区间，不能仅以样本总数满足作为通过条件。

协方差除以样本数只在独立噪声假设下给出均值协方差。存在相关性时，用子窗口均值或重复 trial 估计不确定性，不能声称平均到任意精度。

## 7. 背景插值与标定记录生成

每个 trial、每颗传感器获得三个均值与时间：$(\mu^-_i,t^-_i)$、$(\mu^{on}_i,t^{on}_i)$、$(\mu^+_i,t^+_i)$。

$$
\alpha_i=\frac{t^{on}_i-t^-_i}{t^+_i-t^-_i},\quad
\widehat{\mathbf x}^{bg}_i=(1-\alpha_i)\boldsymbol\mu^-_i+\alpha_i\boldsymbol\mu^+_i
$$

$$
\boxed{\Delta\mathbf x_i=\boldsymbol\mu^{on}_i-\widehat{\mathbf x}^{bg}_i}
$$

要求 $t^-_i<t^{on}_i<t^+_i$；不满足时拒绝记录，不外推。每颗使用自己的背景，不能用参考传感器背景替代其他传感器背景。

质量检查包括窗口稳定性、样本覆盖、背景前后差值和同状态重复性。失败 trial 保留原始数据，设置 `accepted=false` 与原因。基线拟合采用所有 12 颗均通过的共同 trial 集，避免数据列错位。

正负电流实际幅值近似相等时，可另算：

$$
\mathbf o_i=(\Delta\mathbf x_i^+-\Delta\mathbf x_i^-)/2,\qquad
\mathbf e_i=(\Delta\mathbf x_i^++\Delta\mathbf x_i^-)/2
$$

$\mathbf e_i$ 用于诊断非对称性；实际正负输入不等时它不一定应为零。基线保留正负两个训练样本，不强行将偶分量消掉。

## 8. 批量拟合

每个状态只生成增量样本。完成多方向采集后统一求矩阵，不在单个励磁平台上求完整 3×3 映射。

$$
\mathbf X_i=[\Delta\mathbf x_{i,1},\ldots,\Delta\mathbf x_{i,K}],\quad
\mathbf T_i=\arg\min_T\|T\mathbf X_i-\mathbf X_r\|_F^2
$$

$$
\boxed{\mathbf T_i=\mathbf X_r\mathbf X_i^\dagger},\qquad \mathbf T_r=\mathbf I
$$

使用 SVD/最小二乘求解，不显式求 $(X_iX_i^T)^{-1}$。不拟合截距，不用岭回归掩盖缺失激励方向，不让所有矩阵自由缩小到零。普通最小二乘仅作为稳态平均后的基线方法；双方测量噪声仍可能造成估计偏差。

拟合前检查：所有输入有限，样本数充足，矩阵秩为 3，记录奇异值及 $\kappa=\sigma_{max}/\sigma_{min}$。数值秩通过只证明可解，不证明实验激励充分；工程条件数门限需配置，超限应提示补采弱方向。

```python
import numpy as np

def fit_relative(delta, reference_id, rcond=1e-10, max_condition=None):
    # delta[id]: (K, 3)，所有 id 的 K 行必须是相同顺序的已接受训练 trial
    target = np.asarray(delta[reference_id], dtype=float)
    assert target.ndim == 2 and target.shape[1] == 3
    result = {}
    for sensor_id, values in delta.items():
        design = np.asarray(values, dtype=float)
        if design.shape != target.shape or not np.isfinite(design).all():
            raise ValueError("invalid training data")
        if not np.isfinite(target).all():
            raise ValueError("invalid reference data")
        # design @ T.T = target
        solution, _, rank, singular = np.linalg.lstsq(design, target, rcond=rcond)
        if rank < 3:
            raise ValueError("insufficient independent excitation directions")
        condition = singular[0] / singular[-1]
        if max_condition is not None and condition > max_condition:
            raise ValueError("poor excitation conditioning")
        T = np.eye(3) if sensor_id == reference_id else solution.T
        residual = design @ T.T - target
        result[sensor_id] = {
            "T": T, "singular_values": singular, "condition": condition,
            "training_vector_rmse_uT": np.sqrt(np.mean(np.sum(residual**2, axis=1)))
        }
    return result
```

## 9. 独立验证与报告

对验证数据重复同样的筛选、背景插值与作差，然后固定矩阵计算 $z_{i,k}=T_i\Delta x_{i,k}$。不得重新拟合验证集。

$$
\bar z_k=\frac1N\sum_i z_{i,k},\quad
e_k=\sqrt{\frac1N\sum_i\|z_{i,k}-\bar z_k\|^2},\quad
d_k=\max_{i,j}\|z_{i,k}-z_{j,k}\|
$$

同时将全部传感器输出及实际几何位置送入项目已有梯度估计器，记录 $\|\widehat G_k\|_F$。校正前用经过名义坐标转换的增量计算完全相同指标。报告每个励磁条件及重复轮次结果，不只给全体平均值。

注意：参考传感器公共畸变仍存在；基线梯度是名义阵列坐标下的诊断值，不能宣称为精密绝对梯度。若现有梯度估计器强制对称、无迹，则这两项已由模型保证，不能再用它们作为独立正确性证据。

输出建议：逐传感器残差表、按幅值/方向的前后对比、最大通道差值、伪梯度、参考选择、条件数、失败与重采记录、温度与采样率统计。

另外将励磁平台切成正式定位窗口长度，使用同一背景估计和固定矩阵评估短窗指标，窗口长度按实际应用配置。应分别报告长平均与短窗结果；共用背景的相邻短窗并非完全独立样本。

验收采用两级：数据和求解有效性必须通过；性能门限来自项目误差预算。未设绝对门限时只报告改善与重复性，不自动声称达到定位精度。改善率的分母接近零时返回空值，不给无意义百分比。

## 10. 运行时应用

对每颗传感器计算：

$$
\Delta\widehat B_i=T_i\{Q_i[s r_i^{on}]-\widehat x_i^{bg}\}
$$

若背景也以原始计数表示，则可先作差再施加相同的 $Q_i$ 与 $s$。两种实现等价，但不能重复单位或坐标转换。运行输出字段需明确这是参考尺度下的名义 μT 增量。

运行时使用当前姿态与环境下的背景。前后背景插值需要等待后背景，是离线或带延迟的方法；实时系统若只有前背景，必须明确使用保持/因果估计，并单独评估漂移，不能偷偷使用未来数据。

实际定位中保留传感器间的真实空间差异，不强制各传感器相等，不用一致性目标在线抹除梯度。若输入为交流解调输出，应另外验证各通道采样时差和频率响应，本方案不保证动态相位一致。

## 11. 文件与接口规格

建议每次实验独立目录：

```text
run_<timestamp>/
  config.yaml             # 不可变配置快照、传感器表、输入档位、随机种子
  events.csv              # 命令、应答、状态切换、失败、重采
  samples.csv             # 原始有效及无效样本，均保留
  trial_summary.csv       # 每传感器每 trial 的统计、背景与增量
  calibration.json        # 矩阵与适用条件；仅在拟合成功后写出
  validation.csv          # 独立验证逐状态指标
  report.md               # 摘要与异常诊断
```

`samples.csv` 至少包含：`run_id,trial_id,split,phase,sensor_id,bus,tca_mask,sample_seq,t_device,t_host,raw_hx,raw_hy,raw_hz,drdy,err,dor,comm_ok`。可选实际电流、板温、线圈温度；缺测写空值，不伪造 0。没有设备时间或序号时明确缺失及其限制。

`trial_summary.csv` 每行一个 `(trial_id,sensor_id)`，保存三个窗口的有效样本数、均值、均值时间、波动、漂移、alpha、三轴 delta、accepted 和拒绝原因。状态输入保留轴、极性、档位和实际设定值。

`calibration.json` 保存：schema_version、calibration_id、时间、reference_id、sensor_ids、Q、T、名义系数、输入/输出坐标说明、模式寄存器、数据列顺序、拟合方法、训练 trial ID、配置摘要/哈希、奇异值、条件数、训练与验证指标、温度范围。禁止包含未辨识的“真实零偏”。

软件建议分层：

| 模块 | 职责 |
|---|---|
| `SensorAdapter` | 获取原始样本和状态，不静默重排传感器 |
| `ExcitationAdapter` | `set_output(axis, signed_command)`、`all_off()`、可选 `read_current()` |
| `Collector` | 状态机、时间管理、日志、重采与停止 |
| `Preprocessor` | 有效性筛选、坐标转换、窗口统计 |
| `TrialBuilder` | 时间插值背景、增量生成、质量检查 |
| `Calibrator` | 共同 trial 对齐、SVD 拟合、参数保存 |
| `Validator` | 独立数据一致性与梯度评估 |
| `RuntimeCorrector` | 配置校验与固定矩阵应用 |

ROS 话题名、串口格式、信号源 SCPI 命令必须由现有工程确认，通过 adapter 注入，不根据本文臆造。离线算法不依赖 ROS，便于先用已采 CSV 跑通。

## 12. 推荐实现顺序与必要测试

1. 完成离线数据结构、背景插值、矩阵拟合与独立验证；先支持 CSV 导入。
2. 用合成数据验证数学实现，再接入真实采集日志。
3. 实现设备适配器和 dry-run 状态机，确认状态归属、时间戳和异常关闭。
4. 接入硬件，完成单轴低幅 trial，再运行完整训练与验证计划。
5. 通过验证后接入运行时校正；交流和温度补偿另立任务。

必要算法测试：

- 无噪声合成：设置各自可逆响应矩阵、各自静态背景和零偏，三方向励磁，验证恢复 $T_i=A_rA_i^{-1}$。
- 背景线性漂移且采样时刻不对称：验证按时间插值可消除均值层面的线性漂移。
- 只有单轴/两轴激励：必须拒绝秩不足拟合。
- 传感器缺样、trial 乱序、模式不匹配：必须拒绝或显式对齐，不静默错配。
- 合成非均匀工作场：校正后应保留真实传感器间差异；不以零梯度为运行时目标。
- 实时路径不能访问后背景；离线路径正确使用前后背景。
- 异常退出与设备超时：应尝试关闭全部输出并保存失败日志；关闭失败要明确报警。

## 13. 复用与重标定

正常重启恢复相同配置后，重测背景并快速验证即可。整体刚性移动通常不改变相对矩阵，但背景要更新。更换器件、重新焊接、结构变形、模式切换或新增磁性安装件后需重新验证，必要时重标。修改采样或解调链路后重点验证动态一致性。

不设置无依据的固定重标周期或温差门限。以独立验证残差、伪梯度、温度和任务误差预算决定矩阵是否仍有效。
